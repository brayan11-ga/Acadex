# RF-009 · Actualizar prioridad al completar una tarea

| | |
|---|---|
| **Módulo** | Prioridad |
| **Tipo de cambio** | Sin cambios |

## Descripción

El sistema debe actualizar automáticamente la prioridad al completar una tarea, recalculándola con una muestra reciente del historial de la misma categoría.

## Historia de usuario

Como usuario autenticado, necesito que mis prioridades se actualicen al terminar una tarea, con la finalidad de que reflejen cómo trabajo realmente.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario completa una tarea con tiempo real y dificultad real registrados | Se registra la finalización | El sistema recalcula la prioridad de las tareas pendientes de esa categoría con una muestra reciente del historial |
| 2 | La categoría tiene un historial extenso | El sistema recalcula la prioridad | Solo se usan los registros más recientes del historial |
| 3 | No quedan tareas pendientes en esa categoría | El usuario completa la tarea | El sistema no recalcula nada y no genera error |
