# RF-006 · Unirse a un grupo por código

| | |
|---|---|
| **Módulo** | Grupos |
| **Tipo de cambio** | Sin cambios |

## Descripción

La app debe permitir al usuario unirse a un grupo de trabajo por medio de un código.

## Historia de usuario

Como estudiante autenticado en Acadex, necesito usar un código de unión, con la finalidad de trabajar en colaboración con otros integrantes.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario usa un código vigente (dentro de los 30 minutos) | Digita el código y presiona “Unirse” | El sistema lo agrega al grupo y muestra la información del grupo y sus integrantes |
| 2 | El código ya superó los 30 minutos de vigencia | Digita el código y presiona “Unirse” | El sistema informa que el código ha expirado |
| 3 | El código no corresponde a ningún grupo | Digita el código y presiona “Unirse” | El sistema informa que el código es inválido |
| 4 | El usuario ya es integrante del grupo | Digita el código y presiona “Unirse” | El sistema informa que ya pertenece al grupo y no lo agrega de nuevo |
