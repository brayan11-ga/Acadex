# RF-024 · Cerrar sesión

| | |
|---|---|
| **Módulo** | Cuenta y sesión |
| **Tipo de cambio** | Sin cambios |

## Descripción

La app debe permitir al usuario cerrar sesión guardando automáticamente los avances realizados.

## Historia de usuario

Como usuario autenticado, necesito cerrar sesión, con la finalidad de proteger mi cuenta y mi información sin perder mi progreso.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario ha iniciado sesión | Selecciona “Cerrar sesión” | El sistema finaliza la sesión correctamente |
| 2 | La sesión fue cerrada | Intenta entrar a una pantalla protegida | El sistema lo redirige al inicio de sesión |
| 3 | El usuario cerró sesión | Vuelve a abrir la aplicación | El sistema no mantiene la sesión activa |
| 4 | El usuario hizo cambios en sus tareas antes de cerrar sesión | Vuelve a iniciar sesión | Los cambios siguen guardados |
