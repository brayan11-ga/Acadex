# RF-047 · Calendario de tareas

| | |
|---|---|
| **Módulo** | Panel y calendario |
| **Tipo de cambio** | Nuevo |
| **Observación** | Solo backend; el diseño lo definirá el equipo de frontend. |

## Descripción

La app debe permitir al usuario ver sus tareas organizadas en un calendario.

## Historia de usuario

Como usuario autenticado, necesito ver mis tareas en un calendario, con la finalidad de planificar mejor mis días.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario tiene tareas con fecha de entrega | Abre el calendario | El sistema muestra cada tarea en su fecha de entrega |
| 2 | Un día no tiene tareas | El usuario revisa ese día | El sistema lo muestra sin tareas |
| 3 | El usuario cambia la fecha de entrega de una tarea | Vuelve al calendario | La tarea aparece en la nueva fecha |
