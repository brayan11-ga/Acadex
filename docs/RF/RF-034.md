# RF-034 · Reiniciar el cronómetro

| | |
|---|---|
| **Módulo** | Cronómetro |
| **Tipo de cambio** | Sin cambios |

## Descripción

El usuario debe poder reiniciar el cronómetro de una tarea a cero, borrando el tiempo acumulado de esa sesión, previa confirmación obligatoria del sistema.

## Historia de usuario

Como usuario autenticado, necesito reiniciar el cronómetro de una tarea, con la finalidad de corregir un registro de tiempo equivocado.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | La tarea tiene tiempo acumulado | El usuario selecciona “Reiniciar” | El sistema solicita confirmación obligatoria antes de borrar el tiempo |
| 2 | El usuario está en el diálogo de confirmación | Confirma el reinicio | El sistema deja el tiempo acumulado en cero (y detiene el cronómetro si estaba activo) |
| 3 | El usuario está en el diálogo de confirmación | Cancela | El sistema no modifica el tiempo acumulado |
