# RF-043 · Ver integrantes del grupo

| | |
|---|---|
| **Módulo** | Grupos |
| **Tipo de cambio** | Nuevo |
| **Observación** | Implementado. |

## Descripción

La app debe permitir a los integrantes de un grupo ver la lista de integrantes del grupo.

## Historia de usuario

Como integrante de un grupo, necesito ver quiénes forman mi grupo, con la finalidad de saber con quién estoy trabajando.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario es integrante del grupo | Abre el detalle del grupo | El sistema muestra la lista de integrantes con su rol |
| 2 | Un integrante fue expulsado o abandonó el grupo | El usuario consulta la lista | El ex integrante ya no aparece |
| 3 | El usuario no pertenece al grupo | Intenta consultar sus integrantes | El sistema niega el acceso |
