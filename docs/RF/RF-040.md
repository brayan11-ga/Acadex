# RF-040 · Autocompletar tarea con IA desde un PDF

| | |
|---|---|
| **Módulo** | Tareas |
| **Tipo de cambio** | Nuevo |
| **Observación** | Implementado. |

## Descripción

La app debe permitir al usuario autocompletar los datos de una tarea a partir de un archivo PDF, usando inteligencia artificial (Gemini).

## Historia de usuario

Como usuario autenticado, necesito que la app complete los datos de una tarea a partir de un PDF, con la finalidad de ahorrar tiempo al registrarla.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario está creando una tarea y sube un PDF legible con la información de la actividad | Solicita autocompletar con IA | El sistema llena los campos de la tarea con los datos extraídos y deja que el usuario los revise antes de guardar |
| 2 | El archivo subido no es un PDF | Solicita autocompletar con IA | El sistema muestra un error indicando que solo se admiten archivos PDF |
| 3 | El servicio de IA no está disponible o no logra interpretar el PDF | Solicita autocompletar con IA | El sistema muestra un mensaje de error y permite llenar los campos manualmente |
