# RF-017 · Tiempo real de los integrantes por tarea

| | |
|---|---|
| **Módulo** | Estadísticas |
| **Tipo de cambio** | Aclarado |
| **Observación** | Se mantiene separado de RF-011: este RF es por tarea, una a la vez. |

## Descripción

El modo grupal debe mostrar el tiempo real que le tomó a cada integrante completar una tarea específica, consultada de una en una.

## Historia de usuario

Como integrante de un grupo, necesito ver cuánto tardó cada compañero en una tarea concreta, con la finalidad de comparar el esfuerzo en ese momento.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | Los integrantes asignados completaron una tarea grupal | Abre el detalle de esa tarea | El sistema muestra el tiempo real que le tomó a cada integrante |
| 2 | Un integrante asignado aún no termina la tarea | Abre el detalle de la tarea | El sistema muestra que su tiempo aún no está disponible |
| 3 | El usuario no pertenece al grupo de la tarea | Intenta ver el detalle | El sistema niega el acceso |
