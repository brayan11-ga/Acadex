# RF-041 · Categorías predefinidas

| | |
|---|---|
| **Módulo** | Tareas |
| **Tipo de cambio** | Nuevo |
| **Observación** | Implementado. Hay 9 categorías iniciales. |

## Descripción

La app debe ofrecer un listado de categorías predefinidas para elegir al crear o editar una tarea.

## Historia de usuario

Como usuario autenticado, necesito elegir la categoría de mi tarea de una lista, con la finalidad de clasificarla sin escribirla cada vez.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario está creando o editando una tarea | Abre el selector de categoría | El sistema muestra el listado de categorías predefinidas |
| 2 | El usuario no selecciona ninguna categoría | Intenta guardar la tarea | El sistema muestra un error indicando que la categoría es obligatoria |
| 3 | El usuario selecciona una categoría | Guarda la tarea | La tarea queda asociada a esa categoría y se muestra en su detalle |
