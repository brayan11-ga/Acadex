# RF-008 · Registro automático del tiempo real

| | |
|---|---|
| **Módulo** | Cronómetro |
| **Tipo de cambio** | Sin cambios |

## Descripción

El sistema debe registrar automáticamente el tiempo real de una tarea como la suma de los intervalos activos del cronómetro.

## Historia de usuario

Como usuario autenticado en Acadex, necesito que el sistema registre el tiempo real de mis tareas, con la finalidad de saber cuánto me toman realmente.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario inició y pausó el cronómetro varias veces en una tarea | Marca la tarea como completada | El sistema calcula el tiempo real como la suma de los intervalos activos |
| 2 | El cronómetro estuvo pausado durante un intervalo | El sistema calcula el tiempo real | El intervalo en pausa no se suma al tiempo |
| 3 | El usuario completa una tarea | Se registra la finalización | El sistema guarda el tiempo real en el historial de la tarea |
