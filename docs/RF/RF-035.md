# RF-035 · Notificación de mejora de rendimiento

| | |
|---|---|
| **Módulo** | Notificaciones |
| **Tipo de cambio** | Versión futura |
| **Observación** | Se mantiene en la lista pero fuera del alcance de la primera entrega. |

## Descripción

El sistema debe notificar al usuario cuando detecte una mejora en su rendimiento por categoría, ya sea en tiempo real o en dificultad percibida, indicando que se considerará en futuras priorizaciones.

## Historia de usuario

Como usuario autenticado, necesito que me avisen cuando mejore en una categoría, con la finalidad de ver mi progreso y saber que se tendrá en cuenta en futuras priorizaciones.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario completa una tarea y su tiempo real o dificultad percibida en esa categoría mejoró respecto a su promedio | El sistema analiza el resultado | El sistema envía una notificación indicando la mejora y que se considerará en futuras priorizaciones |
| 2 | El rendimiento no mejoró | El sistema analiza el resultado | El sistema no envía ninguna notificación |
| 3 | El usuario tiene las notificaciones desactivadas | Se detecta una mejora | El sistema no envía la notificación |
