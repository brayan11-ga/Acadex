# RF-002 · Adjuntar archivos a tareas

| | |
|---|---|
| **Módulo** | Archivos |
| **Tipo de cambio** | Modificado |
| **Observación** | Por confirmar: si aplica también a tareas individuales o solo a las grupales (ver RF-037). |

## Descripción

La app debe permitir al usuario agregar archivos PDF, DOCX, JPG y PNG, de máximo 5 MB, a las tareas.

## Historia de usuario

Como estudiante autenticado de Acadex, necesito adjuntar archivos a mis tareas, con la finalidad de tener el material de referencia de cada tarea en un solo lugar.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El archivo es PDF, DOCX, JPG o PNG y pesa máximo 5 MB | Presiona “Adjuntar” | El sistema guarda el archivo y muestra su nombre dentro de la tarea |
| 2 | El archivo no es PDF, DOCX, JPG ni PNG | Presiona “Adjuntar” | El sistema muestra un error indicando los formatos permitidos y no guarda el archivo |
| 3 | El archivo supera los 5 MB | Presiona “Adjuntar” | El sistema muestra un error indicando el tamaño máximo y no guarda el archivo |
