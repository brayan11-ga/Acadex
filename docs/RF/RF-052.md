# RF-052 · Datos, código e integrantes en el panel de líder

| | |
|---|---|
| **Módulo** | Panel de líder |
| **Tipo de cambio** | Nuevo |
| **Observación** | Implementado. |

## Descripción

El panel de líder debe mostrar los datos del grupo, el código de acceso vigente y la lista de integrantes, con la opción de expulsar a cada uno.

## Historia de usuario

Como líder, quiero ver los datos, el código y los integrantes de mi grupo, con la finalidad de compartir el código y expulsar integrantes sin cambiar de pantalla.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El líder está en el panel de su grupo | Se carga el panel | El sistema muestra los datos del grupo, el código de acceso vigente y la lista de integrantes |
| 2 | El grupo tiene integrantes | El líder selecciona “Expulsar” junto a un integrante y confirma | El sistema expulsa al integrante, le envía una notificación y actualiza la lista sin salir del panel |
| 3 | El líder seleccionó “Expulsar” para un integrante | Cancela en el diálogo de confirmación | El sistema no modifica la lista de integrantes |
| 4 | El líder aparece en la lista de integrantes | Revisa las opciones de cada integrante | El sistema no ofrece la opción de expulsar sobre el propio líder |
