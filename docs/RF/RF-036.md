# RF-036 · Crear tarea grupal y asignarla

| | |
|---|---|
| **Módulo** | Tareas grupales |
| **Tipo de cambio** | Sin cambios |

## Descripción

El líder de grupo debe poder crear tareas grupales y asignarlas a uno o varios integrantes.

## Historia de usuario

Como líder de grupo, necesito crear una tarea grupal y asignarla a uno o varios integrantes, con la finalidad de distribuir el trabajo y que cada miembro sepa qué le corresponde.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario es el líder del grupo y completa los datos de la tarea | Selecciona uno o varios integrantes y confirma | El sistema crea la tarea del grupo y registra la asignación a cada integrante seleccionado |
| 2 | El líder selecciona a un usuario que no es integrante del grupo | Intenta confirmar la asignación | El sistema muestra un error indicando que el usuario no pertenece al grupo |
| 3 | El usuario es un miembro normal | Intenta crear una tarea grupal | El sistema no permite la acción y muestra un mensaje de falta de permisos |
| 4 | El líder deja campos obligatorios de la tarea en blanco | Intenta confirmar | El sistema marca los campos obligatorios y no crea la tarea |
