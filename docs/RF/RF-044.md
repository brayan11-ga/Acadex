# RF-044 · Ver las tareas del grupo

| | |
|---|---|
| **Módulo** | Tareas grupales |
| **Tipo de cambio** | Nuevo |
| **Observación** | Implementado en el backend; el frontend de tareas grupales está pendiente. |

## Descripción

La app debe permitir a los integrantes de un grupo ver todas las tareas del grupo.

## Historia de usuario

Como integrante de un grupo, necesito ver todas las tareas del grupo, con la finalidad de conocer el avance general.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El grupo tiene tareas registradas | El usuario abre el apartado de tareas del grupo | El sistema muestra todas las tareas del grupo |
| 2 | El grupo no tiene tareas | El usuario abre el apartado de tareas del grupo | El sistema muestra un mensaje indicando que aún no hay tareas |
| 3 | El usuario no pertenece al grupo | Intenta ver las tareas del grupo | El sistema niega el acceso |
