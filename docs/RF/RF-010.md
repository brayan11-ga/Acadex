# RF-010 · Notificación de la tarea de mayor prioridad

| | |
|---|---|
| **Módulo** | Notificaciones |
| **Tipo de cambio** | Fusionado |
| **Observación** | Fusiona RF-010 y RF-013. |

## Descripción

El sistema debe notificar al usuario cuándo una tarea adquiere la mayor prioridad para iniciarla, indicando su nombre y su fecha de entrega.

## Historia de usuario

Como usuario autenticado, necesito recibir una notificación cuando una tarea adquiere la mayor prioridad, con la finalidad de saber qué tarea debo empezar en ese momento.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario tiene las notificaciones activadas y una tarea pasa a tener la mayor prioridad | El sistema recalcula las prioridades | El sistema envía una notificación con el nombre y la fecha de entrega de esa tarea |
| 2 | El usuario tiene las notificaciones de priorización desactivadas | Una tarea pasa a tener la mayor prioridad | El sistema no envía la notificación |
| 3 | La tarea ya tenía la mayor prioridad y ya fue notificada | El sistema recalcula y sigue siendo la de mayor prioridad | El sistema no envía una notificación repetida |
