# RF-014 · Marcar tarea como completada

| | |
|---|---|
| **Módulo** | Tareas |
| **Tipo de cambio** | Sin cambios |

## Descripción

La app debe permitir al usuario cambiar una tarea incompleta al estado de completada cuando la haya terminado.

## Historia de usuario

Como usuario autenticado, necesito marcar una tarea como completada, con la finalidad de mantener mi lista organizada y actualizada.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario tiene una tarea en progreso | Hace clic en “Completada” | El sistema cambia el estado a completada y la registra en el historial |
| 2 | La tarea no tiene tiempo registrado en el cronómetro | Hace clic en “Completada” | El sistema permite completarla pero advierte que conviene registrar el tiempo |
| 3 | La tarea ya está completada | Intenta completarla otra vez | El sistema no la registra de nuevo en el historial |
