# RF-007 · Prioridad automática

| | |
|---|---|
| **Módulo** | Prioridad |
| **Tipo de cambio** | Sin cambios |

## Descripción

La app debe asignar automáticamente la prioridad de las tareas usando la fecha de entrega como factor principal y los promedios de tiempo real y dificultad real por categoría como factores secundarios.

## Historia de usuario

Como usuario autenticado, necesito que la app priorice mis tareas automáticamente, con la finalidad de saber cuál debo empezar primero.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario tiene historial de tareas completadas en la categoría | Crea una tarea nueva de esa categoría | El sistema calcula la prioridad con la fecha de entrega como factor principal y los promedios de tiempo real y dificultad real como factores secundarios |
| 2 | Hay varias tareas pendientes con fechas de entrega distintas | El sistema calcula las prioridades | La tarea con la fecha de entrega más cercana recibe la mayor prioridad |
| 3 | Dos tareas tienen la misma fecha de entrega | El sistema calcula las prioridades | El desempate se hace con los promedios de tiempo y dificultad real de su categoría |
