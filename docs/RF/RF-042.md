# RF-042 · Ver mis grupos con mi rol

| | |
|---|---|
| **Módulo** | Grupos |
| **Tipo de cambio** | Nuevo |
| **Observación** | Implementado. |

## Descripción

La app debe mostrar al usuario los grupos a los que pertenece, indicando su rol (líder o miembro) en cada uno.

## Historia de usuario

Como usuario autenticado, necesito ver mis grupos y mi rol en cada uno, con la finalidad de saber en cuáles puedo gestionar y en cuáles solo participo.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario pertenece a uno o más grupos | Accede a “Mis grupos” | El sistema muestra cada grupo con su rol (líder o miembro) |
| 2 | El usuario no pertenece a ningún grupo | Accede a “Mis grupos” | El sistema muestra un mensaje indicando que aún no tiene grupos y ofrece crear uno o unirse |
| 3 | El usuario acaba de unirse a un grupo con un código | Vuelve a “Mis grupos” | El grupo aparece en la lista con el rol de miembro |
