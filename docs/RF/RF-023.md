# RF-023 · Inicio de sesión

| | |
|---|---|
| **Módulo** | Cuenta y sesión |
| **Tipo de cambio** | Modificado |
| **Observación** | Se elimina el inicio de sesión con Google (decisión del equipo). |

## Descripción

La app debe permitir al usuario iniciar sesión mediante su correo electrónico y contraseña.

## Historia de usuario

Como usuario registrado, necesito iniciar sesión con mi correo y contraseña, con la finalidad de acceder a mis tareas y grupos.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario tiene una cuenta activa y las credenciales son correctas | Ingresa su correo y contraseña y envía el formulario | El sistema inicia la sesión y lo redirige a la página principal |
| 2 | El usuario ingresa un correo o contraseña incorrectos | Envía el formulario | El sistema muestra “Correo o contraseña inválidos” y no inicia sesión |
| 3 | La cuenta del usuario está bloqueada | Intenta iniciar sesión | El sistema informa que la cuenta está bloqueada y no permite el acceso |
| 4 | El usuario deja el correo o la contraseña vacíos | Envía el formulario | El sistema marca los campos obligatorios y no inicia sesión |
