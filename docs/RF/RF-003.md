# RF-003 · Gestión de tareas

| | |
|---|---|
| **Módulo** | Tareas |
| **Tipo de cambio** | Modificado |
| **Observación** | Se agregan descripción y tiempo estimado, que ya existen en la app. |

## Descripción

La app debe permitir al usuario agregar, editar y eliminar tareas, con nombre, descripción, categoría, fecha de entrega, dificultad estimada (1 a 5) y tiempo estimado.

## Historia de usuario

Como estudiante autenticado de Acadex, necesito agregar, editar y eliminar mis tareas, con la finalidad de tener mi espacio de tareas actualizado continuamente.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario completa nombre, categoría, fecha de entrega, dificultad estimada (1 a 5) y tiempo estimado | Presiona el botón de crear tarea | El sistema muestra la tarea creada en la lista de tareas |
| 2 | El usuario modifica los campos de una tarea sin dejarlos en blanco | Presiona “Actualizar” | El sistema muestra los cambios en la tarea seleccionada |
| 3 | El usuario deja un campo obligatorio en blanco al crear o editar | Presiona “Crear” o “Actualizar” | El sistema muestra un error y no guarda los cambios |
| 4 | El usuario decide eliminar una tarea (con o sin archivos adjuntos) y acepta la confirmación | Presiona el botón de papelera | El sistema elimina la tarea junto con sus archivos y registros relacionados |
