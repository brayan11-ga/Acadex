# RF-025 · Prioridad de tareas grupales

| | |
|---|---|
| **Módulo** | Prioridad |
| **Tipo de cambio** | Sin cambios |
| **Observación** | Pendiente de implementar. |

## Descripción

El sistema debe ajustar automáticamente la prioridad de una tarea grupal nueva, considerando el promedio de dificultad real y tiempo real del historial de tareas de la misma categoría dentro del grupo.

## Historia de usuario

Como integrante de un grupo, necesito que las tareas nuevas del grupo se prioricen con el historial del grupo, con la finalidad de repartir mejor el esfuerzo.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El grupo tiene historial de tareas completadas en la categoría | El líder crea una tarea grupal de esa categoría | El sistema ajusta la prioridad con el promedio de dificultad real y de tiempo real del historial de esa categoría en el grupo |
| 2 | El grupo no tiene historial en la categoría | El líder crea una tarea grupal | El sistema prioriza solo por fecha de entrega |
| 3 | El líder tiene un historial personal distinto al del grupo | Crea una tarea grupal | El sistema usa únicamente el historial del grupo, no el personal |
