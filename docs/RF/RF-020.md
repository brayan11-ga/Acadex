# RF-020 · Editar perfil

| | |
|---|---|
| **Módulo** | Perfil |
| **Tipo de cambio** | Modificado |
| **Observación** | Decisión del equipo: desde el perfil no se cambian el correo ni la contraseña. Se agrega el teléfono. |

## Descripción

La app debe permitir al usuario cambiar su nombre de usuario, teléfono, foto de perfil y descripción personal.

## Historia de usuario

Como usuario autenticado, necesito editar mi nombre de usuario, teléfono, foto de perfil y descripción, con la finalidad de mantener mi información actualizada.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario está en su perfil | Modifica su nombre de usuario, teléfono, foto o descripción y guarda | El sistema actualiza los datos y muestra un mensaje de éxito |
| 2 | El usuario deja vacío un campo obligatorio (por ejemplo, el nombre de usuario) | Intenta guardar los cambios | El sistema muestra un error específico y no actualiza el perfil |
| 3 | El usuario abrió el formulario de edición | Selecciona “Cancelar” | El sistema descarta los cambios y vuelve a la vista del perfil |
| 4 | El usuario está en su perfil | Revisa los datos de su cuenta | El correo y la contraseña no se pueden modificar desde el perfil |
