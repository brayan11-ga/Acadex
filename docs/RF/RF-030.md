# RF-030 · Ver el cronómetro en tiempo real

| | |
|---|---|
| **Módulo** | Cronómetro |
| **Tipo de cambio** | Sin cambios |

## Descripción

El sistema debe mostrar al usuario el tiempo acumulado del cronómetro en tiempo real mientras trabaja en una tarea activa.

## Historia de usuario

Como usuario autenticado, necesito ver el cronómetro avanzando mientras trabajo, con la finalidad de saber cuánto tiempo llevo en la tarea.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El cronómetro de la tarea está activo | El usuario mira la tarea | El sistema muestra el tiempo acumulado avanzando en tiempo real |
| 2 | El cronómetro está pausado | El usuario mira la tarea | El sistema muestra el tiempo acumulado sin avanzar |
| 3 | El usuario cerró la app con el cronómetro activo | Vuelve a abrir la tarea | El sistema conserva y muestra el tiempo acumulado correcto |
