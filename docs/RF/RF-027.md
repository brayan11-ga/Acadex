# RF-027 · Eliminar grupo

| | |
|---|---|
| **Módulo** | Grupos |
| **Tipo de cambio** | Sin cambios |
| **Observación** | La eliminación es en cascada (tareas, archivos, historial y métricas del grupo). |

## Descripción

La app debe permitir al líder eliminar su propio grupo junto con todos sus integrantes y los datos de priorización del grupo.

## Historia de usuario

Como líder de grupo, necesito eliminar mi grupo, con la finalidad de retirar grupos que ya no se necesitan.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario es el líder del grupo | Selecciona “Eliminar grupo” | El sistema solicita confirmación |
| 2 | El líder confirma la eliminación | Se procesa la solicitud | El sistema elimina el grupo con sus integrantes, tareas, archivos y datos de priorización, y el grupo ya no aparece en la lista |
| 3 | Aparece la confirmación de eliminación | El líder cancela | El sistema no elimina el grupo |
| 4 | El usuario es un miembro normal | Intenta eliminar el grupo | El sistema no permite la acción y muestra un mensaje de falta de permisos |
