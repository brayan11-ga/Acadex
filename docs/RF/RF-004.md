# RF-004 · Crear grupo de trabajo

| | |
|---|---|
| **Módulo** | Grupos |
| **Tipo de cambio** | Sin cambios |

## Descripción

La app debe permitir al usuario crear dentro de sí misma un grupo de trabajo.

## Historia de usuario

Como estudiante autenticado en Acadex, necesito crear un grupo de estudio, con la finalidad de asignar tareas grupales.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario ingresa un nombre de grupo y una descripción dentro de los límites permitidos | Presiona “Crear grupo” | El sistema muestra el nuevo grupo en la sección de grupos |
| 2 | El usuario deja el nombre o la descripción en blanco | Presiona “Crear grupo” | El sistema indica que debe completar los campos y no crea el grupo |
| 3 | El usuario crea un grupo correctamente | Se completa la creación | El usuario queda registrado en el grupo con el rol de líder |
