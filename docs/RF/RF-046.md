# RF-046 · Panel de inicio

| | |
|---|---|
| **Módulo** | Panel y calendario |
| **Tipo de cambio** | Nuevo |
| **Observación** | Implementado; falta ajustarlo para cuando haya muchos datos. |

## Descripción

La app debe mostrar al usuario un panel de inicio con el resumen de sus tareas.

## Historia de usuario

Como usuario autenticado, necesito un panel con el resumen de mis tareas, con la finalidad de saber de un vistazo cómo voy.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario tiene tareas registradas | Ingresa al panel | El sistema muestra el resumen de sus tareas |
| 2 | El usuario no tiene tareas | Ingresa al panel | El sistema muestra un mensaje invitando a crear su primera tarea |
| 3 | El usuario completa una tarea | Vuelve al panel | El resumen refleja la tarea como completada |
