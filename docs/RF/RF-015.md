# RF-015 · Prioridad inicial sin historial

| | |
|---|---|
| **Módulo** | Prioridad |
| **Tipo de cambio** | Sin cambios |

## Descripción

El sistema debe asignar prioridad máxima a la primera tarea y, desde la segunda, priorizar por fecha de entrega hasta tener historial suficiente de la categoría.

## Historia de usuario

Como usuario nuevo, necesito que mis primeras tareas se prioricen por fecha de entrega, con la finalidad de recibir un orden útil aunque aún no tenga historial.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario no tiene otras tareas registradas | Crea su primera tarea | El sistema le asigna la prioridad máxima |
| 2 | El usuario ya tiene una tarea y no hay historial suficiente de la categoría | Crea una segunda tarea | El sistema prioriza ambas por fecha de entrega |
| 3 | La categoría ya tiene historial suficiente | Crea una tarea nueva | El sistema deja de priorizar solo por fecha y aplica la prioridad automática completa (RF-007) |
