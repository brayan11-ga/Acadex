# RF-037 · Notificación al líder por archivo subido

| | |
|---|---|
| **Módulo** | Tareas grupales |
| **Tipo de cambio** | Modificado |
| **Observación** | Antes notificaba a todos los integrantes; ahora solo al líder (así está construido). |

## Descripción

El sistema debe notificar al líder del grupo cuando un integrante sube un archivo como avance de una tarea grupal que tiene asignada. Solo el integrante con la tarea asignada puede subir archivos.

## Historia de usuario

Como líder de grupo, necesito recibir una notificación cuando un integrante sube un avance, con la finalidad de revisarlo a tiempo.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El integrante tiene la tarea grupal asignada | Sube un archivo PDF, DOCX, JPG o PNG de máximo 5 MB | El sistema guarda el archivo y envía una notificación al líder del grupo |
| 2 | El usuario es integrante del grupo pero no tiene esa tarea asignada | Intenta subir un archivo | El sistema no permite la subida y muestra un mensaje de falta de permisos |
| 3 | El archivo no cumple el formato o supera los 5 MB | El integrante intenta subirlo | El sistema muestra un error, no guarda el archivo y no envía notificación |
