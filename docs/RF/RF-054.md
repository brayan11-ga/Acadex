# RF-054 · Gestionar tareas grupales desde el panel

| | |
|---|---|
| **Módulo** | Tareas grupales (panel de líder) |
| **Tipo de cambio** | Nuevo |
| **Observación** | Pendiente. |

## Descripción

El panel de líder debe permitir gestionar las tareas grupales del grupo (crear, asignar y consultar).

## Historia de usuario

Como líder, quiero gestionar las tareas grupales desde mi panel, con la finalidad de asignarlas sin salir de él.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El líder está en su panel y completa los datos de una tarea | Selecciona integrantes y confirma la creación | El sistema crea la tarea grupal y registra la asignación a los integrantes seleccionados |
| 2 | El grupo tiene tareas registradas | El líder abre la sección de tareas del panel | El sistema muestra las tareas del grupo con sus integrantes asignados |
| 3 | El grupo no tiene tareas | El líder abre la sección de tareas del panel | El sistema muestra un mensaje indicando que aún no hay tareas y ofrece crear una |
