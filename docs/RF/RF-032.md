# RF-032 · Pausa automática por límite

| | |
|---|---|
| **Módulo** | Cronómetro |
| **Tipo de cambio** | Sin cambios |

## Descripción

El sistema debe pausar automáticamente el cronómetro cuando haya corrido de forma continua más tiempo del límite configurado por el usuario.

## Historia de usuario

Como usuario autenticado, necesito que el cronómetro se pause solo al pasar mi límite continuo, con la finalidad de no registrar tiempo cuando olvidé pararlo.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El cronómetro está activo y el usuario tiene un límite configurado | El tiempo continuo supera ese límite | El sistema pausa el cronómetro y notifica que se alcanzó el límite |
| 2 | El usuario no tiene un límite configurado | El cronómetro lleva mucho tiempo activo | El sistema no lo pausa automáticamente |
| 3 | El cronómetro se pausó automáticamente | El usuario presiona “Reanudar” | El sistema reactiva el cronómetro y empieza a contar un nuevo intervalo |
