# RF-011 · Promedio de tiempo por categoría en el grupo

| | |
|---|---|
| **Módulo** | Estadísticas |
| **Tipo de cambio** | Aclarado |
| **Observación** | Se mantiene separado de RF-017: este RF abarca todas las tareas de una categoría. |

## Descripción

El sistema debe mostrar en el grupo el promedio de tiempo real de cada integrante, calculado sobre todas las tareas de una misma categoría.

## Historia de usuario

Como integrante de un grupo, necesito ver el promedio de tiempo real de cada integrante por categoría, con la finalidad de entender cómo se reparte el trabajo en general.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El grupo tiene tareas completadas en una categoría | Selecciona esa categoría en las estadísticas del grupo | El sistema muestra el promedio de tiempo real de cada integrante en esa categoría |
| 2 | Un integrante no ha completado tareas de esa categoría | Consulta las estadísticas de la categoría | El sistema muestra “Sin datos” para ese integrante |
| 3 | El usuario no pertenece al grupo | Intenta consultar las estadísticas del grupo | El sistema niega el acceso |
