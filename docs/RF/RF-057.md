# RF-057 · Enlace “Admin” en el menú

| | |
|---|---|
| **Módulo** | Admin |
| **Tipo de cambio** | Nuevo |
| **Observación** | Implementado. |

## Descripción

La app debe mostrar el enlace “Admin” en el Sidebar solo a los usuarios administradores, y este debe llevar a admin.

## Historia de usuario

Como administrador, quiero un enlace al panel de administración en el menú, con la finalidad de llegar rápido a él.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario es administrador y tiene la sesión activa | Observa el menú lateral | El sistema muestra el enlace “Admin” |
| 2 | El usuario no es administrador | Observa el menú lateral | El sistema no muestra el enlace “Admin” |
| 3 | El administrador está viendo el menú lateral | Presiona “Admin” | El sistema lo lleva al panel de administración (/admin) |
