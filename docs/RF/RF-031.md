# RF-031 · Iniciar y pausar el cronómetro

| | |
|---|---|
| **Módulo** | Cronómetro |
| **Tipo de cambio** | Sin cambios |

## Descripción

El usuario debe poder iniciar y pausar manualmente el cronómetro mientras trabaja en una tarea activa.

## Historia de usuario

Como usuario autenticado, necesito iniciar y pausar el cronómetro de una tarea, con la finalidad de medir solo el tiempo que realmente trabajo.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | La tarea está en progreso y el cronómetro está detenido | El usuario presiona “Iniciar” | El sistema activa el cronómetro y comienza a acumular tiempo |
| 2 | El cronómetro está activo | El usuario presiona “Pausar” | El sistema detiene el cronómetro y guarda el momento de la pausa |
| 3 | El cronómetro está pausado | El usuario presiona “Reanudar” | El sistema reactiva el cronómetro sin perder el tiempo ya acumulado |
