# RF-012 · Revisar estados y avances de tareas

| | |
|---|---|
| **Módulo** | Tareas |
| **Tipo de cambio** | Sin cambios |

## Descripción

La app debe permitir al usuario revisar los estados, avances e información de las tareas programadas.

## Historia de usuario

Como usuario autenticado, necesito revisar los estados y avances de mis tareas, con la finalidad de monitorear mi progreso.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario está en el tablero principal | Selecciona una tarea específica | El sistema muestra su estado actual y su avance |
| 2 | Tiene tareas pendientes, en progreso y completadas | Abre su lista de tareas | El sistema muestra cada tarea con su estado actual |
| 3 | El usuario no tiene tareas registradas | Abre su lista de tareas | El sistema muestra un mensaje indicando que aún no hay tareas |
