# RF-045 · Ver quién tiene asignada una tarea

| | |
|---|---|
| **Módulo** | Tareas grupales |
| **Tipo de cambio** | Nuevo |
| **Observación** | Implementado en el backend; en la interfaz se mostrará con un botón para revelar. |

## Descripción

La app debe permitir ver qué integrantes tienen asignada una tarea grupal.

## Historia de usuario

Como integrante de un grupo, necesito ver quién tiene asignada cada tarea, con la finalidad de saber a quién consultar.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | Una tarea grupal tiene integrantes asignados | El usuario selecciona la opción de ver asignados | El sistema muestra los integrantes asignados a esa tarea |
| 2 | La tarea fue asignada a varios integrantes | El usuario selecciona la opción de ver asignados | El sistema muestra a todos los integrantes asignados |
| 3 | El usuario no pertenece al grupo de la tarea | Intenta ver los asignados | El sistema niega el acceso |
