# RF-053 · Restringir el panel de líder

| | |
|---|---|
| **Módulo** | Panel de líder |
| **Tipo de cambio** | Nuevo |
| **Observación** | el botón ya se oculta a los miembros, pero no lo he verificado. Confirma que la ruta también esté protegida y no solo el botón. |

## Descripción

La app debe restringir el acceso al panel de líder al líder del grupo, y no mostrar el botón “Panel de líder” a los demás integrantes.

## Historia de usuario

Como líder, quiero que solo yo acceda al panel de mi grupo, con la finalidad de que ningún otro integrante gestione el grupo.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario es el líder del grupo | Intenta acceder al panel de líder | El sistema permite el acceso |
| 2 | El usuario es un miembro normal del grupo | Abre el detalle del grupo | El sistema no muestra el botón “Panel de líder” |
| 3 | El usuario es un miembro normal o no pertenece al grupo | Escribe directamente la dirección del panel de líder | El sistema niega el acceso y muestra un mensaje de falta de permisos |
