# RF-022 · Abandonar un grupo

| | |
|---|---|
| **Módulo** | Grupos |
| **Tipo de cambio** | Modificado |
| **Observación** | Se agrega la restricción del líder. Relacionado con RF-050. |

## Descripción

La app debe permitir a los integrantes de un grupo abandonarlo de forma voluntaria. El líder no puede abandonar su propio grupo.

## Historia de usuario

Como integrante de un grupo, necesito abandonarlo de forma voluntaria, con la finalidad de salir cuando ya no deba participar en él.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario es miembro del grupo (no líder) | Selecciona “Abandonar grupo” y confirma | El sistema lo remueve del grupo y lo redirige a la lista de grupos |
| 2 | El usuario es el líder del grupo | Intenta abandonarlo | El sistema le impide salir e informa que el líder no puede abandonar su propio grupo |
| 3 | El usuario inició el proceso de abandono | Cancela la confirmación | El sistema no lo remueve y regresa a la pantalla anterior |
