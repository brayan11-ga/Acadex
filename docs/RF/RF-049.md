# RF-049 · Invitar a un usuario a un grupo

| | |
|---|---|
| **Módulo** | Grupos |
| **Tipo de cambio** | Nuevo |
| **Observación** | Por confirmar: existe la notificación de invitación, pero falta confirmar si la invitación es una función completa. |

## Descripción

La app debe permitir invitar a un usuario a un grupo y notificarle la invitación.

## Historia de usuario

Como líder de grupo, necesito invitar a un usuario a mi grupo, con la finalidad de sumarlo sin que tenga que buscar el código.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario es líder y el invitado es un usuario registrado que no está en el grupo | Envía la invitación | El sistema registra la invitación y le envía una notificación al invitado |
| 2 | El usuario invitado no existe en Acadex | El líder intenta invitarlo | El sistema muestra un error indicando que el usuario no está registrado |
| 3 | El usuario invitado ya es integrante del grupo | El líder intenta invitarlo | El sistema informa que ya pertenece al grupo y no envía la invitación |
