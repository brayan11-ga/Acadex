# RF-056 · Identificar al usuario administrador

| | |
|---|---|
| **Módulo** | Admin |
| **Tipo de cambio** | Nuevo |
| **Observación** | Implementado en el slice de auth (Redux) |

## Descripción

El sistema debe identificar a los usuarios con rol de administrador (es_admin) y mantener ese dato en el estado global de sesión de la app.

## Historia de usuario

Como administrador, quiero que el sistema reconozca mi rol al iniciar sesión, con la finalidad de acceder a las funciones de administración.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | La cuenta tiene rol de administrador | El usuario inicia sesión | El sistema identifica el rol y lo guarda en el estado global de la sesión |
| 2 | La cuenta no tiene rol de administrador | El usuario inicia sesión | El sistema lo identifica como usuario normal y no habilita funciones de administración |
| 3 | El administrador tiene la sesión activa | Navega entre las pantallas de la app | El sistema mantiene su rol sin pedirle iniciar sesión de nuevo |
| 4 | El administrador tiene la sesión activa | Cierra sesión | El sistema elimina su rol del estado global de la sesión |
