# RF-038 · Ver mis tareas grupales asignadas

| | |
|---|---|
| **Módulo** | Tareas grupales |
| **Tipo de cambio** | Sin cambios |

## Descripción

Cada integrante debe poder ver las tareas grupales que el líder le asignó.

## Historia de usuario

Como integrante de un grupo, necesito ver las tareas que me asignaron, con la finalidad de saber qué debo entregar.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario tiene tareas grupales asignadas | Accede a su sección de tareas asignadas | El sistema muestra las tareas que el líder le asignó |
| 2 | El usuario no tiene tareas asignadas | Accede a su sección de tareas asignadas | El sistema muestra un mensaje indicando que no tiene tareas asignadas |
| 3 | Una tarea del grupo fue asignada a otros integrantes pero no a él | Accede a su sección de tareas asignadas | La tarea no aparece en su lista |
