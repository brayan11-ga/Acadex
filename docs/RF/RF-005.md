# RF-005 · Código de acceso al grupo

| | |
|---|---|
| **Módulo** | Grupos |
| **Tipo de cambio** | Sin cambios |

## Descripción

La app debe permitir generar un código de acceso al grupo de trabajo.

## Historia de usuario

Como líder de grupo en Acadex, necesito generar un código de acceso, con la finalidad de añadir participantes a mi grupo.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | Ya existe un grupo creado y el usuario es su líder | Presiona “Generar código de unión” | El sistema muestra un código único en la configuración del grupo |
| 2 | No han pasado 30 minutos desde que se generó el código anterior | Presiona “Generar código de unión” | El sistema indica que debe esperar 30 minutos antes de generar uno nuevo |
| 3 | El usuario es miembro del grupo pero no líder | Intenta generar un código de acceso | El sistema no permite la acción y muestra un mensaje de falta de permisos |
