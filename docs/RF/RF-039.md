# RF-039 · Bloqueo de cuenta por intentos fallidos

| | |
|---|---|
| **Módulo** | Cuenta y sesión |
| **Tipo de cambio** | Nuevo |
| **Observación** | Columnas en la BD listas; la lógica de desbloqueo está pendiente. |

## Descripción

El sistema debe bloquear la cuenta del usuario después de varios intentos fallidos consecutivos de inicio de sesión y permitir su posterior desbloqueo.

## Historia de usuario

Como usuario, necesito que mi cuenta se bloquee tras varios intentos fallidos de inicio de sesión, con la finalidad de evitar que alguien adivine mi contraseña.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario ya falló 4 intentos consecutivos | Falla el quinto intento | El sistema bloquea la cuenta y muestra un mensaje de cuenta bloqueada |
| 2 | La cuenta está bloqueada | El usuario intenta iniciar sesión, incluso con credenciales correctas | El sistema no permite el acceso y muestra el mensaje de cuenta bloqueada |
| 3 | El usuario tiene intentos fallidos pero no llegó al límite | Inicia sesión con las credenciales correctas | El sistema inicia la sesión y reinicia el contador de intentos fallidos |
| 4 | La cuenta estaba bloqueada y ya pasó el tiempo de bloqueo | El usuario inicia sesión con credenciales correctas | El sistema desbloquea la cuenta y permite el acceso |
