# RF-029 · Buscar tareas

| | |
|---|---|
| **Módulo** | Tareas |
| **Tipo de cambio** | Sin cambios |
| **Observación** | Aplazado: los filtros por nombre y fecha no están en la interfaz por decisión del equipo. |

## Descripción

La app debe permitir al usuario encontrar cualquier tarea agendada, en proceso o completada por medio de su nombre o fecha de entrega.

## Historia de usuario

Como usuario autenticado, necesito buscar mis tareas por nombre o fecha de entrega, con la finalidad de encontrarlas rápidamente.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | Existen varias tareas registradas | El usuario escribe parte del nombre en el buscador | El sistema muestra las tareas cuyo nombre coincide total o parcialmente |
| 2 | Existen tareas con distintas fechas de entrega | El usuario busca por una fecha de entrega | El sistema muestra las tareas con esa fecha |
| 3 | No hay coincidencias | Se ejecuta la búsqueda | El sistema muestra “No se encontraron resultados” |
| 4 | El usuario tenía una búsqueda activa | Borra el texto del buscador | El sistema muestra todas las tareas de nuevo |
