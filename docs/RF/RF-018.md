# RF-018 · Dificultad promedio del grupo por categoría

| | |
|---|---|
| **Módulo** | Estadísticas |
| **Tipo de cambio** | Sin cambios |
| **Observación** | Pendiente de implementar. |

## Descripción

El sistema debe calcular automáticamente el promedio de dificultad real de las tareas completadas por los integrantes de un grupo, agrupado por categoría.

## Historia de usuario

Como integrante de un grupo en Acadex, necesito ver la dificultad promedio por categoría de las tareas completadas por el grupo, con la finalidad de conocer qué tipo de tareas le cuesta más al equipo.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El grupo ha completado al menos una tarea en alguna categoría | El usuario accede a las estadísticas del grupo | El sistema muestra, por categoría, el promedio de dificultad real, el promedio de tiempo y el total de tareas del grupo |
| 2 | El grupo no ha completado ninguna tarea | El usuario accede a las estadísticas del grupo | El sistema muestra un mensaje indicando que aún no hay datos suficientes |
| 3 | Un integrante del grupo completa una tarea grupal | El sistema registra la finalización | El sistema actualiza automáticamente los promedios del grupo para esa categoría |
