# RF-016 · Dificultad real al terminar una tarea

| | |
|---|---|
| **Módulo** | Tareas |
| **Tipo de cambio** | Sin cambios |

## Descripción

La app debe permitir al usuario registrar una calificación de dificultad real del 1 al 5 al terminar una tarea.

## Historia de usuario

Como usuario autenticado, necesito calificar la dificultad real de una tarea al terminarla, con la finalidad de que mis próximas prioridades sean más precisas.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario marca una tarea como completada | Ingresa una dificultad real del 1 al 5 y confirma | El sistema guarda la dificultad real en el historial de la tarea |
| 2 | El usuario ingresa una dificultad fuera del rango 1 a 5 | Intenta confirmar | El sistema muestra un error y no guarda la calificación |
| 3 | El usuario registra la dificultad real | Se guarda en el historial | El sistema actualiza el promedio de dificultad de la categoría |
