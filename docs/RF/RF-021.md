# RF-021 · Expulsar integrantes

| | |
|---|---|
| **Módulo** | Grupos |
| **Tipo de cambio** | Sin cambios |

## Descripción

La app debe permitir al líder de un grupo expulsar a cualquier integrante del grupo.

## Historia de usuario

Como líder de grupo, necesito expulsar a un integrante, con la finalidad de mantener el grupo bajo control cuando sea necesario.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario es el líder del grupo y el integrante a expulsar no es el líder | Selecciona al integrante y confirma la expulsión | El sistema lo elimina del grupo, le envía una notificación de que fue expulsado y actualiza la lista de integrantes |
| 2 | El usuario es un miembro normal | Intenta expulsar a otro integrante | El sistema muestra “No tienes permiso” y no realiza la expulsión |
| 3 | El líder seleccionó un integrante para expulsar | Cancela en el diálogo de confirmación | El sistema cierra el diálogo y no modifica el grupo |
| 4 | La persona seleccionada ya no pertenece al grupo | El líder intenta expulsarla | El sistema informa que ya no es miembro y no realiza ninguna acción |
