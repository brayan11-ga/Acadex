# RF-001 · Registro de usuarios

| | |
|---|---|
| **Módulo** | Cuenta y sesión |
| **Tipo de cambio** | Modificado |
| **Observación** | Se elimina el registro con Google (decisión del equipo). |

## Descripción

La app debe permitir al usuario crear una cuenta mediante su correo electrónico y una contraseña personal.

## Historia de usuario

Como estudiante nuevo en Acadex, necesito crear una cuenta con mi correo y una contraseña, con la finalidad de poder crear o unirme a grupos de trabajo.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario ingresa un correo con formato válido, una contraseña válida y un nombre de usuario de máximo 20 caracteres sin espacios | Presiona “Crear cuenta” | El sistema crea la cuenta y muestra un mensaje de confirmación |
| 2 | El correo ya está registrado en Acadex | Presiona “Crear cuenta” | El sistema informa que el correo ya está registrado |
| 3 | La contraseña no cumple los requisitos (8 a 20 caracteres, al menos una mayúscula, sin espacios) | Presiona “Crear cuenta” | El sistema indica qué requisito no se cumplió |
| 4 | El usuario deja campos obligatorios vacíos | Presiona “Crear cuenta” | El sistema marca los campos obligatorios y no crea la cuenta |
