# RF-028 · Activar o desactivar notificaciones

| | |
|---|---|
| **Módulo** | Notificaciones |
| **Tipo de cambio** | Sin cambios |

## Descripción

El sistema debe permitir al usuario activar o desactivar las notificaciones de priorización.

## Historia de usuario

Como usuario autenticado, necesito activar o desactivar las notificaciones de priorización, con la finalidad de recibir solo los avisos que me sirven.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario está en la configuración | Activa la opción de notificaciones | El sistema habilita las notificaciones de priorización |
| 2 | El usuario está en la configuración | Desactiva la opción | El sistema deja de enviar notificaciones de priorización |
| 3 | El usuario cambió su preferencia | Sale y vuelve a entrar | El sistema mantiene la configuración |
