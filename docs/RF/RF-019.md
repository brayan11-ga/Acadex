# RF-019 · Recuperar contraseña

| | |
|---|---|
| **Módulo** | Cuenta y sesión |
| **Tipo de cambio** | Sin cambios |

## Descripción

La app debe permitir al usuario recuperar su contraseña mediante su correo electrónico.

## Historia de usuario

Como usuario que olvidó su contraseña, necesito restablecerla desde mi correo electrónico, con la finalidad de volver a entrar a mi cuenta.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario tiene una cuenta activa y recuerda su correo | Selecciona “Olvidé mi contraseña” y envía su correo | El sistema envía un enlace de restablecimiento válido por tiempo limitado |
| 2 | El usuario ingresa un correo que no está registrado | Envía el formulario de restablecimiento | El sistema muestra un mensaje genérico sin revelar si el correo existe |
| 3 | Pasó el tiempo de vigencia del enlace | El usuario intenta usarlo | El sistema indica que el enlace expiró y ofrece solicitar uno nuevo |
| 4 | El usuario tiene un enlace válido | Ingresa una nueva contraseña que cumple los requisitos y confirma | El sistema actualiza la contraseña y lo redirige al inicio de sesión |
