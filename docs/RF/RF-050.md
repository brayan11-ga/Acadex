# RF-050 · Transferir el liderazgo del grupo

| | |
|---|---|
| **Módulo** | Grupos |
| **Tipo de cambio** | Nuevo |
| **Observación** | Por definir con el equipo. Necesario porque el líder no puede abandonar su grupo (RF-022). |

## Descripción

La app debe permitir al líder transferir el liderazgo del grupo a otro integrante.

## Historia de usuario

Como líder de grupo, necesito pasar el liderazgo a otro integrante, con la finalidad de poder dejar el grupo sin que se quede sin líder.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario es el líder y el grupo tiene otros integrantes | Selecciona a un integrante y confirma la transferencia | El integrante seleccionado pasa a ser líder y el anterior queda como miembro |
| 2 | El grupo no tiene otros integrantes | El líder intenta transferir el liderazgo | El sistema informa que no hay a quién transferirlo y sugiere eliminar el grupo |
| 3 | El usuario es un miembro normal | Intenta transferir el liderazgo | El sistema no permite la acción y muestra un mensaje de falta de permisos |
| 4 | El líder inició la transferencia | Cancela en el diálogo de confirmación | El sistema no modifica los roles |
