# RF-033 · Configurar el límite del cronómetro

| | |
|---|---|
| **Módulo** | Cronómetro |
| **Tipo de cambio** | Sin cambios |

## Descripción

El usuario debe poder configurar el tiempo máximo continuo que puede correr el cronómetro antes de pausarse automáticamente, como una configuración global de su cuenta.

## Historia de usuario

Como usuario autenticado, necesito configurar el tiempo máximo continuo del cronómetro en mi perfil, con la finalidad de recibir una pausa automática cuando llevo demasiado tiempo sin descanso.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario está en la configuración de su perfil | Ingresa un valor mayor a 0 y guarda | El sistema actualiza el límite y lo aplica a todos sus cronómetros |
| 2 | El usuario ingresa 0 o un valor negativo | Intenta guardar | El sistema muestra un error indicando que el límite debe ser mayor a cero |
| 3 | El usuario no desea pausas automáticas | Deja el campo en blanco y guarda | El sistema desactiva la pausa automática |
