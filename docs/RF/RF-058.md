# RF-058 · Proteger la ruta /admin

| | |
|---|---|
| **Módulo** | Admin |
| **Tipo de cambio** | Nuevo |
| **Observación** | Verificado por revisión estática: `RutaAdmin` redirige cuando el usuario no es administrador y los endpoints de administración dependen de `requerir_admin` en el backend. Falta conservar pruebas de comportamiento cuando se modifique este control. |

## Descripción

La app debe impedir que un usuario que no es administrador acceda a /admin, aunque escriba la URL directamente.

## Historia de usuario

Como administrador, quiero que solo los administradores entren a /admin, con la finalidad de proteger las funciones administrativas.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario tiene sesión pero no es administrador | Escribe /admin directamente en la barra de direcciones | El sistema niega el acceso y lo redirige fuera del panel de administración |
| 2 | El usuario no ha iniciado sesión | Escribe /admin directamente en la barra de direcciones | El sistema lo redirige al inicio de sesión |
| 3 | El usuario es administrador | Escribe /admin o entra desde el menú | El sistema permite el acceso |
| 4 | El usuario no es administrador | Intenta usar directamente las funciones de administración (por ejemplo, llamando a la API) | El backend rechaza la solicitud por falta de permisos |
