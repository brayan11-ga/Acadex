# RF-048 · Notificación de tarea por vencer

| | |
|---|---|
| **Módulo** | Notificaciones |
| **Tipo de cambio** | Nuevo |
| **Observación** | Implementado. |

## Descripción

El sistema debe notificar al usuario cuando una de sus tareas está próxima a vencer.

## Historia de usuario

Como usuario autenticado, necesito que me avisen cuando una tarea esté por vencer, con la finalidad de no dejarla pasar.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El usuario tiene una tarea pendiente cuya fecha de entrega se acerca | El sistema detecta la cercanía del vencimiento | El sistema envía una notificación con el nombre y la fecha de entrega de la tarea |
| 2 | La tarea ya está completada | Se acerca su fecha de entrega | El sistema no envía ninguna notificación |
| 3 | El usuario tiene las notificaciones desactivadas | Una tarea se acerca a su vencimiento | El sistema no envía la notificación |
