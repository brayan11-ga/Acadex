# RF-055 · Estadísticas del grupo en el panel

| | |
|---|---|
| **Módulo** | Estadísticas (panel de líder) |
| **Tipo de cambio** | Nuevo |
| **Observación** | Pendiente. |

## Descripción

El panel de líder debe mostrar las estadísticas del grupo (tiempo real por integrante y dificultad promedio por categoría).

## Historia de usuario

Como líder, quiero ver las estadísticas del grupo en mi panel, con la finalidad de evaluar cómo se reparte el trabajo.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | El grupo ha completado al menos una tarea | El líder abre las estadísticas del panel | El sistema muestra el tiempo real por integrante y la dificultad promedio por categoría |
| 2 | El grupo no ha completado ninguna tarea | El líder abre las estadísticas del panel | El sistema muestra un mensaje indicando que aún no hay datos suficientes |
| 3 | Un integrante completa una tarea del grupo | El líder vuelve a abrir las estadísticas | El sistema muestra los valores actualizados con esa tarea |
