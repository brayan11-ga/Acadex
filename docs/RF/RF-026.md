# RF-026 · Historial de tareas completadas

| | |
|---|---|
| **Módulo** | Tareas |
| **Tipo de cambio** | Sin cambios |

## Descripción

La app debe permitir al usuario ver todas las tareas que ya registró como completadas.

## Historia de usuario

Como usuario autenticado, necesito ver las tareas que ya completé, con la finalidad de consultar lo que ya realicé.

## Escenarios

| # | Dado que (Contexto) | Cuando (Evento) | Entonces (Resultado esperado) |
|---|---|---|---|
| 1 | Existen tareas completadas | El usuario ingresa a “Historial” | El sistema muestra la lista de tareas finalizadas |
| 2 | Se visualiza el historial | El usuario observa las tareas | El sistema muestra el nombre, la fecha y el estado de cada una |
| 3 | No existen tareas completadas | El usuario ingresa a “Historial” | El sistema muestra un mensaje indicando que no hay tareas |
