# RNF-006 · Desempeño y escalabilidad

| | |
|---|---|
| **Categoría** | Desempeño y escalabilidad |

## Descripción

El sistema debe recalcular y actualizar la prioridad de las tareas en menos de 2 segundos después de completar una tarea, o de unirse/salir de un grupo
