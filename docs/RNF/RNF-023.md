# RNF-023 · Seguridad y privacidad

| | |
|---|---|
| **Categoría** | Seguridad y privacidad |
| **Requisitos relacionados** | [RF-053](../RF/RF-053.md), [RF-058](../RF/RF-058.md) |
| **Observación** | Relacionado con RF-053 y RF-058 (control de acceso por rol). |

## Descripción

El sistema debe restringir la creación/asignación de tareas grupales, la expulsión de integrantes y la eliminación del grupo exclusivamente al líder o creador, validando su rol en cada solicitud
