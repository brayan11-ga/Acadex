# RNF-025 · Confiabilidad y disponibilidad

| | |
|---|---|
| **Categoría** | Confiabilidad y disponibilidad |

## Descripción

El cronómetro debe mantener la precisión del tiempo y conservar el progreso acumulado aunque la app se cierre, se pierda la conexión o el dispositivo se reinicie
