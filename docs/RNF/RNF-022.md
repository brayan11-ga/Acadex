# RNF-022 · Seguridad y privacidad

| | |
|---|---|
| **Categoría** | Seguridad y privacidad |

## Descripción

El sistema debe garantizar que solo los integrantes de un grupo puedan ver la información, tareas y métricas de ese grupo (aislamiento de datos entre grupos)
