# RNF-030 · Confiabilidad y disponibilidad

| | |
|---|---|
| **Categoría** | Confiabilidad y disponibilidad |

## Descripción

Al eliminar un grupo, el sistema debe borrar de forma completa y consistente toda la información asociada (tareas, archivos, métricas, historial), sin dejar datos huérfanos
