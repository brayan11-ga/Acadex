# RNF-029 · Seguridad y privacidad

| | |
|---|---|
| **Categoría** | Seguridad y privacidad |

## Descripción

El enlace o código de recuperación de contraseña enviado por correo debe ser único, de un solo uso y expirar en un tiempo limitado
